Nepal floods dashboard 
•	Built an interactive disaster analytics dashboard analyzing flood impacts across Nepal, including deaths, affected/displaced population, infrastructure, crop, and financial damage. 
•	Developed DAX measures and a Date Table for dynamic KPI and time-based analysis. 
•	Created province/district comparisons, Top-N analysis, slicers, and a custom Nepal Shape Map for geographic impact visualization. 
•	Tech: Power BI, DAX, Power Query, Excel, Data Modeling.
